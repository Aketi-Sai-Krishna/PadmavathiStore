Padmavathi Stores web logo assets

Recommended:
- Navbar logo: padmavathi-stores-logo-transparent.png or .webp
- Favicon: favicon.ico or favicon-32.png
- iOS home screen: apple-touch-icon.png
- PWA/app icon: icon-192.png and icon-512.png

Put files in your Vite project's public/ folder:
  <img src="/padmavathi-stores-logo-transparent.png" alt="Padmavathi Stores" />

The SVG file is an SVG wrapper around the high-resolution transparent PNG, not a true path-traced vector. The original logo is a JPEG, so inspect transparency around fine edges and the eyes on both light and dark backgrounds before launch.
